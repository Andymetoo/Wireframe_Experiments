Authoring:
  Select Board brush articulated arm / left side; Edit STOWED or Edit WORKING.
  Scene position and rotation handles move the actual head; coordinates are editable in the Inspector.
  Save each endpoint; then enable Use saved endpoints in Play.
  Deployment slider and 0/25/50/75/100% buttons preview the resulting existing arm articulation.
  The initial endpoints come from the current authored mechanism, head tilt and heights, never defaults.
  Endpoint data is serialized on the existing rig and all edits use Undo.
  The single arm requires equal horizontal endpoint distance to the pivot (2 mm tolerance).
  A mismatch displays both length errors. Correct the pivot/arm length or use Project both endpoints onto arm circle; save both again.
  Height and head rotation can differ at each endpoint; intermediate heights/rotations interpolate.
  Existing legacy Apply Brush Geometry to Simulation remains available when saved endpoints are disabled.
  Preview state remains transient and saving returns the mechanism to stowed.

Spring:
  Rig Inspector controls Compliance travel (m), Spring return (rad/s), Damping ratio.
  Aurora defaults: .12 m, 12 rad/s, 1.0 respectively.
  Minimal prefab serialization can add complianceTravel: 0.12, springReturn: 12, springDamping: 1.
  Leave useAuthoredEndpoints: 0 (or absent) to retain current approved geometry/calibration.
  Core fallback travel is .45 m only for the longer original procedural brush envelope; authored rig overrides it.
  BrushCompression and BrushTravelLimited expose actual compression and exhaustion of finite travel.
  Contact projection tracks the rounded-board normal; a bounded implicit damped spring restores the head on release.
  The runtime visible disc consumes BrushWorldX/Z, exactly the point used for snow sweeping.
  Overtravel is a real geometric limit: if the authored brush projects into boards farther than its permitted travel, it cannot fully clear the kickplate. No invisible extra travel is supplied. The Inspector diagnoses straight-board reach beyond travel and the runtime telemetry reports the limit.

Required Game integration (camera agent owns):
  NewSession: clone/create runtime config, call brushRig.ApplyAuthoredConfiguration(config,out error), then Simulation(config).
  Log any failed endpoint application; scene geometry is retained on failure.
  Runtime rig Pose must use Mechanism.From(Sim.Config), not the unchanged serialized calibration.
  Legacy geometry mismatch warning only applies when useAuthoredEndpoints is false.
